# Data Structures & Algorithms — Interview Prep

This repository is my personal workspace for learning Data Structures and Algorithms (DSA) from the ground up, with the goal of preparing for software engineering interviews.

## No AI Was Used

**This project is written entirely by hand, with zero AI assistance.** No code, explanations, comments, or solutions here were generated, autocompleted, or suggested by any AI tool. Every line reflects my own understanding, mistakes, and problem-solving process.

The point of this repo is to actually **learn**, not to produce working code as fast as possible. Using AI would defeat that purpose, so it's intentionally excluded from every step of this project — research, writing, debugging, and review included.

## Goal

Build genuine fluency in core DSA topics so I can:
- Solve unseen problems under interview conditions
- Explain my reasoning and trade-offs out loud
- Recognize patterns quickly (two pointers, sliding window, DFS/BFS, DP, etc.)
- Analyze time and space complexity correctly

1. Pick a problem (LeetCode, Blind 75, NeetCode 150, etc.)
